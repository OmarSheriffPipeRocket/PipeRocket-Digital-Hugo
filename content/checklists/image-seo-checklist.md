Image SEO is making every image on a site fast to load, easy for search engines to understand, and accessible to people using a screen reader: file naming, format and compression, alt text, responsive delivery, and discoverability through sitemaps and structured data. ## How to use this checklist

Work it in order: get the file itself right first (name, format, size), then alt text and performance, then the discoverability layer. Most sites lose the most to unoptimised file size, so start there if you only have time for one pass.

## Get the file basics right

Use descriptive, keyword-aware file names instead of a camera's default IMG_1234.jpg, since the file name is a real (small) ranking signal search engines read. Choose the right format for the job, WebP or AVIF for most photos, SVG for icons and logos, compress every image without a visible quality loss, and size images to their actual display dimensions rather than shipping a full-resolution original the browser has to shrink.

## Write alt text and context that actually helps

Write specific, descriptive alt text for every meaningful image, since it is what screen readers announce and what search engines use to understand the image. Leave alt text empty rather than missing entirely for purely decorative images, and support important images with surrounding text or a caption that reinforces what the image shows.

## Optimise for performance

Serve responsive images with srcset and sizes so a phone loads a phone-sized image instead of a desktop one. Lazy-load everything below the fold so the initial page load is not held up by images a visitor has not scrolled to yet, and set width and height attributes on every image so the browser reserves the right space and the page does not jump as it loads.

## Make images discoverable

Include your images in your XML sitemap or a dedicated image sitemap so search engines find them without depending on a crawl of every page. Add ImageObject structured data on pages where image search traffic matters, and host images on your own domain rather than a third-party service that could change URLs or disappear.

## Handle legal and quality basics

Use only licensed or genuinely original images, and confirm usage rights before anything goes live, an unlicensed image is a legal problem, not just an SEO one. Avoid generic stock photography that adds no real information on pages where a real screenshot, diagram, or original graphic would earn more trust and more clicks from image search.

## Frequently Asked Questions

### What is image SEO?

Image SEO is optimising the images on a site so they load fast, are understandable to search engines, and are accessible to people using assistive technology. It covers file names, format and compression, alt text, responsive delivery, and discoverability through sitemaps and structured data.

### What is the best image format for SEO?

WebP or AVIF for most photos, since both offer strong compression with good quality at a smaller file size than JPEG or PNG. Use SVG for icons, logos, and simple graphics, since it scales without quality loss and is typically a tiny file. Reserve PNG for images that specifically need transparency and cannot use WebP.

### How do I write good alt text?

Describe what the image actually shows in specific, natural language, as if describing it to someone who cannot see it, and skip generic phrases like "image of" or keyword-stuffed lists. For purely decorative images that add no information, leave the alt attribute empty rather than omitting it, so screen readers correctly skip it.

### Do images really affect page speed?

Yes, often more than any other single factor. Unoptimised, oversized images are the most common cause of slow Largest Contentful Paint scores, since large image files often are the largest content element on a page. Compression, correct sizing, and lazy-loading typically produce the fastest, cheapest speed win available.

### Does image SEO help with AI search?

Indirectly. AI systems and image search both rely on alt text, surrounding context, and structured data to understand what an image shows and represents, since they cannot fully interpret pixels the way a human can. Clear, accurate alt text and context help both traditional image search and AI-driven visual understanding.
