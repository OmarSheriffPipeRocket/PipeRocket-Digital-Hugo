Mobile SEO is making sure the version of your site Google actually crawls, the mobile one, has the same content, speed, and usability as desktop, since Google has indexed mobile-first for years. This is narrower than a full technical SEO audit, it is specifically the mobile layer: parity, speed on real devices, and usability signals. ## How to use this checklist

Start with parity: if mobile is missing content, links, or structured data that desktop has, nothing else on this list matters as much. Then work through speed, usability, and the Search Console reports, which surface the issues real visitors are already hitting.

## Confirm mobile-first indexing and parity

Google indexes the mobile version of your pages, so confirm it has the same content, links, headings, and structured data as desktop, missing content on mobile is missing content to Google, full stop. Set the viewport meta tag so pages render at device width instead of a shrunk desktop layout, and confirm nothing important is hidden from crawlers behind a tab, accordion, or interstitial.

## Nail speed and Core Web Vitals on mobile

Test LCP, INP, and CLS specifically on mobile in PageSpeed Insights, since mobile scores are consistently worse than desktop on the same page. Lazy-load below-the-fold images, defer non-critical scripts, and confirm a CDN and caching are actually helping mobile visitors, who are more likely to be on a slower connection.

## Get the design and usability right

Size and space tap targets so a thumb does not misfire on the wrong link, and use a font size visitors can read without pinching to zoom. Confirm no page forces horizontal scrolling, and remove or shrink any interstitial that covers the content the moment someone lands, Google has penalised intrusive mobile interstitials for years.

## Work the mobile search and Search Console reports

Review the Mobile Usability report in Search Console and fix everything it flags, then check Core Web Vitals segmented by device, since a healthy desktop average can hide a broken mobile experience. Confirm mobile pages are actually indexed and nothing is accidentally blocking them.

## Handle the technical mobile details

Serve responsive images with srcset and sizes so devices load the right size instead of a full desktop image squeezed into a small screen. If a legacy separate mobile subdomain (m.yoursite.com) still exists, confirm it is not creating duplicate content, and check that no content or interactive element fails to render on mobile browsers.

## Keep monitoring mobile

Test key pages on real devices on a regular cadence, not just an emulator, since real devices catch what simulators miss. Compare mobile conversion rate against desktop and investigate any large gap, and re-test mobile usability and speed after every redesign or template change, since it is the easiest thing to quietly break.

## Frequently Asked Questions

### What is mobile SEO?

Mobile SEO is optimising a site for the mobile version Google actually crawls and indexes: content parity with desktop, mobile page speed and Core Web Vitals, touch-friendly usability, and a clean Mobile Usability report in Search Console.

### What is mobile-first indexing?

Mobile-first indexing means Google predominantly uses the mobile version of your pages for indexing and ranking, not desktop. If your mobile pages are missing content, links, or structured data that desktop has, Google effectively never sees what is missing, regardless of how complete your desktop site is.

### How do I check my mobile Core Web Vitals?

Use PageSpeed Insights or the Core Web Vitals report in Search Console, both of which report mobile and desktop separately. Test on mobile specifically rather than trusting a desktop score, since mobile scores are almost always worse on the same page due to slower connections and less processing power.

### What is Google's intrusive interstitial penalty?

Google can suppress rankings for mobile pages that show an interstitial, like a large popup or app-install banner, that covers the main content immediately after a visitor arrives from search. Banners for legal requirements like cookie consent are exempt; promotional interstitials covering content are not.

### Is mobile SEO different from responsive design?

Responsive design is one way to deliver a good mobile experience, adapting layout to screen size from a single codebase. Mobile SEO is broader: it also covers content parity, mobile-specific speed, tap-target usability, and what Search Console reports about your mobile pages, regardless of which technical approach you use to be responsive.
